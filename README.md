# Local Artisan Marketplace

A web-based e-commerce platform designed to help local artisans sell products to buyers in their community.

## Project Purpose

The goal of this project is to create a marketplace where local sellers can list products and buyers can search for, purchase, review, and return products.

The project is being developed as part of a Software Project Management course.

## Main Features

Planned features include:

- User account creation and login
- Buyer and seller accounts
- Product listings
- Product search and filtering
- Shopping cart
- Checkout and ordering
- Order history and tracking
- Reviews
- Returns
- Buyer/seller messaging
- Seller product management
- Seller analytics

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Git / GitHub

## Running the Project

1. Clone the repository to your computer.

2. Open the project folder in VS Code.

3. Install the required Python packages by running:

   `pip install -r requirements.txt`

4. Run the Flask application by running:

   `python app.py`

5. Open a web browser and go to:

   `http://127.0.0.1:5000`

The website should now be running locally on your computer.
